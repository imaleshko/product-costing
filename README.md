# Калькуляція собівартості

Вебзастосунок для формування планової калькуляції виробничої собівартості в розрізі по виробах. Користувач вводить статті витрат для виробу, система розраховує собівартість на одиницю та на випуск (партію) і виводить зведену калькуляційну таблицю з можливістю експорту в Excel.

## Можливості

- Додавання виробу з первинними статтями витрат через форму
- Автоматичний розрахунок калькуляції на бекенді (на одиницю та на випуск)
- Зведена таблиця калькуляції по всіх виробах
- Експорт калькуляції у файл `.xlsx`

## Стек технологій

**Бекенд**
- Node.js, Express
- MongoDB + Mongoose

**Фронтенд**
- React, Vite
- SheetJS (`xlsx`)

## Запуск

Проєкт складається з двох частин — бекенду та фронтенду, які запускаються окремо. Бекенд має працювати на порту `3000`, оскільки саме на нього налаштовані запити фронтенду.

### 1. Бекенд

```bash
cd backend
npm install
```

Створіть файл `.env` у теці `backend/` за зразком:

```env
MONGODB_URI=mongodb+srv://<user>:<password>@<cluster>/<dbname>
PORT=3000
```

Запуск у режимі розробки (з автоперезапуском через nodemon):

```bash
npm run dev
```

Або звичайний запуск:

```bash
npm start
```

Після старту в консолі з'являться повідомлення `MongoDB Connected` та `Listening on port 3000`.

### 2. Фронтенд

У новому терміналі:

```bash
cd frontend
npm install
npm run dev
```

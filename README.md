# Калькуляція собівартості

Вебзастосунок для формування планової калькуляції виробничої собівартості в розрізі по виробах. Користувач вводить статті витрат для виробу, система розраховує собівартість на одиницю та на випуск (партію) і виводить зведену калькуляційну таблицю з можливістю експорту в Excel.

## Можливості

- Додавання виробу з первинними статтями витрат через форму
- Автоматичний розрахунок калькуляції на бекенді (на одиницю та на випуск)
- Зведена таблиця калькуляції по всіх виробах
- Експорт калькуляції у файл `.xlsx`

## Стек технологій

**Бекенд**
- Node.js, Express
- MongoDB + Mongoose

**Фронтенд**
- React, Vite
- SheetJS (`xlsx`)
